# craftrate

Craft filesystem rate paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/craftrate/

## Install / run

```bash
git clone https://github.com/theworker02/craftrate.git
cd craftrate
node src/cli.js
node --test
```
